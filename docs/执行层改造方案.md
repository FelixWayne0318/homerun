# 执行层改造方案（对照 polymarket-copy-trading-bot）

时间：2026-11-18（Asia/Shanghai）
对象：Homerun 本地 Polymarket 单平台，`traders_copy_trade` 实盘链路

## 一、现状核对（基于当前代码，不是推测）

| 参考仓库的做法 | Homerun 现状 | 结论 |
|---|---|---|
| BUY 按股数下单，避免 USDC 预算超买 | `order_manager` 已是 `shares = notional / price`，并有 `_MIN_LIVE_SHARES` 下限 | 已满足，不需改 |
| BUY 用 FOK，SELL 用 FAK | 实盘 `time_in_force` 取 leg，缺省 `GTC` | 有差距，可配置化 |
| 发送前落 pending（at-most-once） | `place_order` 有 metadata 幂等键、`_persist_orders`、`_validate_and_reserve_order` | 骨架已有 |
| 回包三分：成交 / 拒绝 / 未知 | 未知一律 `FAILED` 且释放额度 | **真实缺陷，已修** |
| 未决单占额度，交对账 | 有 `fast_idempotency`、`_sync_provider_open_orders`、reconciliation worker | 机制可用，缺“未知单”入口 |
| 深度为累计档位、价格带 0.05–0.95 | `min_live_liquidity_usd=150`、`max_entry_price=0.98`，档位累计逻辑部分具备 | P1，本轮不动 |

关键发现：代码在传输层已经明确“FAK/IOC 的 BUY 超时后不重试，避免重复链上单”，但异常路径仍把订单记 `FAILED` 并释放额度。这意味着一旦交易所实际成交，本地会认为失败、额度被释放，下一个信号可以在同一方向再开一笔，形成事实上的重复敞口。

## 二、方案与优先级

### P0-1 未知结果不再当失败（已执行）
- 在 `place_order` 中增加 `submit_attempted`：仅在签名订单真正递交给 CLOB 前置为 True。
- 该标志为 True 且方向为 BUY、且非鉴权失败时，异常路径改为：
  - `OrderStatus.PENDING`
  - `error_message = unknown_submit_outcome: ...`
  - **保留额度不释放**
- 鉴权失败、未递交（同步 transport / 前置闸门失败）仍按 `FAILED` 释放，保持原语义。
- 验收：`pytest -k "live_execution or place_order"` 25 项通过；`pytest -k "order_manager or orchestrator"` 257 项通过。

### P0-2 BUY 的 FOK 必须是股数口径（已执行 + 已配置）
- 原实现：FOK/FAK 走 `MarketOrderArgs`，BUY 时 `amount = price × size`（SDK 按 USDC 解释）。成交价优于限价时会多买股，正是参考仓库点名的问题。
- 修改：BUY 的 FOK/FAK 改走 `OrderArgs(price, size)` + `postOrder(FOK)`；SELL 仍用 `MarketOrderArgs(amount=shares)`，因为 SELL 的 `amount` 本来就是股数。
- 配置：仅对「跟单实盘微仓1」加 `live_time_in_force=FOK`，`mode=live` 才生效，影子模拟与其它策略的 leg 不受影响。
- 验收：`place_order` 语法检查通过；25 项单测通过；影子 26 笔 / 20 持仓未变；实盘微仓 0 单 0 仓、仍 paused。

### P1 收紧口径（本轮不做）
1. **深度改为累计档位**：`min_live_liquidity_usd` 应统计盘口累计深度而非单档，避免“看着有量、实际吃不到”。
2. **价格带上限 0.95**：当前 `max_entry_price=0.98`，尾部赔率过低；参考实现用 0.95。
3. **SELL 用 FAK**：退出路径目前沿用 leg 的 TIF，应在退出侧固定 FAK，避免挂单等不到对手盘。
   - 风险：退出改动影响现有 20 个影子仓的模拟语义，需单独灰度。

### P2 选人过滤（不做）
参考仓库的信号层（PMWallets 托管、胜率置信区间下界、剔除单一最佳市场）属于选人质量，和本地钱包池逻辑不同源，迁移成本高、收益不确定。本轮明确不动。
