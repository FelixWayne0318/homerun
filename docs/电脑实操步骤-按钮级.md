# Homerun 电脑实操步骤（按钮级）

> 本手册按 2026-11-15 本机运行界面核对。页面中的市场数、机会数、新闻数、持仓和盈亏会随行情变化，不能作为固定验收数字；按钮名称和所在页面按当时 UI 记录。
>
> 当前部署口径：**Polymarket 单平台**。Kalshi 行情入口和跨平台套利策略已停用；不要在操作记录里寻找 Kalshi 市场卡片。

## 0. 操作前安全约定

- 第一遍建议只做 **只读巡检**：浏览页面、查看筛选器、打开弹窗，但不提交实盘订单。
- 沙盒/影子机器人只记录模拟账本，不使用真实现金；实盘订单有二次确认，未配置实盘凭证时不要强行下单。
- 除巡检末尾的“紧急停止”说明外，不点击 `停止`、`Kill Switch`、删除、覆盖配置或实盘确认按钮。
- 顶部显示的数字每轮扫描都会变化；重点看“页面能否打开、数据是否刷新、按钮是否可用”，不要把某一刻的数字当成固定标准。

## 1. 打开系统

1. 打开本机浏览器。
2. 在地址栏输入前端地址：`http://127.0.0.1:3000`，按回车。
3. 等待首页加载。正常情况下左侧出现导航栏，顶部出现状态条。
4. 如需确认后端是否在线：另开一个标签页访问 `http://127.0.0.1:8000/health`，页面返回 `{"status":"ok"}` 即表示后端健康检查通过。
5. 如果前端空白或接口超时：
   - 按 `Cmd + R` 刷新一次；
   - 仍异常时执行 `Cmd + Shift + R` 强制刷新；
   - 再异常时检查启动器是否仍在运行，不要直接删除数据库或缓存目录。

如果系统尚未启动：在 Finder 中进入 `/Users/ahs/Projects/homerun/scripts/launchers/`，双击 `Homerun.command`，等待前后端启动后再访问上面的前端地址。

## 2. 先看顶部状态条

进入首页后，从左到右核对以下状态：

| 状态项 | 正常观察点 | 异常含义 |
|---|---|---|
| 推送连接 | 显示“已连接” | 未连接时页面不会自动刷新，先检查后端服务 |
| 扫描 | 显示最近扫描时间 | 时间持续变旧才需要关注；首次打开有延迟可等待一轮扫描 |
| 工作器 | 显示类似 `10/11 · 1 警告` | 当前 `news` worker 为主动停用，琥珀色警告属于已知状态；若其他 worker 变红或停止，需要记录日志 |
| 市场 | 显示市场数量 | 数量随目录更新变化 |
| 交易员 / 新闻 / 天气 / 加密 | 显示各自数量 | 源未配置或停用时为 0，不等于系统崩溃 |
| 信号 | 显示 `P/S/X/F` 计数 | 机会刷新后计数变化 |
| 策略 | 显示策略总数 | 本机核对时为 29 个启用策略 |
| 漏斗 | 显示信号到机会的转化 | 比例为 0 时结合机会列表判断 |
| 日盈亏 / 敞口 / 挂单 | 显示金额和笔数 | 沙盒金额以页面账户为准 |
| 事件 | 显示最近事件时间和条数 | 事件流应持续滚动 |

顶部右侧按钮从左到右通常包括：

- 账户按钮：当前账户名，例如 `沙盒测试1`。点击可切换账户。
- 搜索框：占位文案为 `Search markets, wallets, traders...`。输入关键词后按回车触发搜索。
- `Worker and VPN status`：查看 worker 与 VPN/代理状态。
- 主题按钮：文案类似 `主题：自动。点击切换到 浅色。`，点击只切换深浅色主题。
- `Pause`：暂停全局调度；第一遍巡检不要点击。

## 4. 机会页面

### 4.1 进入页面

1. 点击左侧导航 `机会`。
2. 等待市场卡片或列表加载。

### 4.2 查看子标签

页面顶部子标签按来源分组，本机核对时可见：

- `市场 75`（数量会变化）
- `交易员 0`
- `新闻 0`
- `天气 0`
- `加密货币 0`
- `体育 5`

操作：

1. 点击 `市场`：查看 Polymarket 市场机会。
2. 点击 `交易员`：查看跟随交易员信号；计数为 0 时，本页没有可跟随的买入卡片。
3. 点击 `新闻`、`天气`、`加密货币`：对应数据源未启用或暂无信号时显示空列表，属正常现象。
4. 主动搜索后，页面可能临时出现“搜索结果”子标签；清空搜索或刷新后回到默认分组。

### 4.3 切换视图和筛选

子标签右侧有三个视图图标：

- 卡片图标：卡片视图。
- 列表图标：列表视图。
- 终端图标：终端表格视图。

筛选区可见按钮和控件：

- `Settings`：打开机会显示设置。
- `Analyze Visible`：分析当前可见机会。
- 每页大小下拉框：选项包含 25 / 50 / 100 / 200。
- `已跟踪`：只看已跟踪对象。
- `分组`：按分组显示。
- `池`：查看池中机会。
- `其他`：其他来源分组。
- `显示已过滤`：显示被过滤的条目。
- `Refresh` / `刷新`：手动刷新机会。
- 搜索框：输入市场、钱包或交易员关键词。
- `Show Empty`：显示空结果分组。
- `Min %`：最小优势过滤。
- 风险滑块：按风险分数过滤。
- 排序方向按钮：切换升序/降序。

巡检建议：先点卡片图标，再点列表图标，最后点终端图标；只查看布局，不保存筛选修改。

### 4.4 查看市场卡片

市场卡片上通常可见：

- 市场问题、价格、优势、策略标签、风险等级。
- `分析`：打开该市场的分析详情。
- `AI`：打开 AI 分析。
- `搜索相关新闻文章`：检索相关新闻。
- 外部 `PM` 链接：打开 Polymarket 对应市场。

操作：

1. 任选一张卡片，点击 `分析` 查看详情。
2. 返回机会列表后，点击 `AI` 查看分析内容。
3. 如卡片有 `搜索相关新闻文章`，点击查看新闻检索结果。
4. 外部 `PM` 链接只用于核对原市场，不要在外部网站直接下单。

### 4.5 买入入口（条件触发，第一遍可不提交）

买入入口只在有可用信号时出现。

1. 在 `机会` 页点击 `交易员` 子标签。
2. 如果计数为 0 或没有买入卡片，说明本轮没有可跟单的交易员信号，跳过本小节。
3. 如果卡片上有绿色 `买入` 按钮，点击它打开下单弹窗。

下单弹窗标题为 `下单`，字段和按钮如下：

- 顶部：市场问题、方向徽章、价格、置信度。
- `订单类型`：
  - `市价`：默认，按当前价格尝试成交。
  - `限价`：点击后出现价格输入框，可输入 0.01–0.99 的限价。
- `仓位大小`：预设金额为 `$5`、`$10`、`$25`、`$50`、`$100`、`$250`；下方自定义金额输入框可填写其他正数金额。
- `执行方`：列表显示已启用机器人；本机核对时可见两个影子机器人：`新闻机器人 1`、`沙盒测试机器人1`，标签为 `影子`。
- `交易摘要`：显示 `成本`、`入场`、`股数`、`若Yes`、`ROI/优势`。
- 底部按钮：
  - 未选机器人时显示 `选择机器人`。
  - 选择后显示 `买入 $金额`。
  - 如果选择的是实盘机器人，会进入红色二次确认页，按钮为 `取消` 和 `确认实盘订单`；巡检时点击 `取消`。

影子订单提交后，成功横幅显示 `订单已下达`，可点 `前往交易者` 查看机器人，或点 `完成` 关闭弹窗。第一遍巡检建议打开弹窗核对字段后直接点右上角关闭，不提交。

## 5. 机器人页面

1. 点击左侧导航 `机器人`。
2. 页面顶部可见：
   - `停止`：全局停止按钮，巡检时不要点击。
   - `Cortex`：进入 Cortex/AI 机器人视图。
   - `设置`：打开机器人设置。
3. 状态徽章：
   - `RUNNING`：机器人运行中。
   - `SHADOW`：影子模式，模拟成交。
   - `OPEN`：当前有未平仓持仓。

### 5.1 子标签

页面子标签：

- `概览`：默认页面，查看已验证已结算 P&L、最近一天盈亏、未验证笔数、运行中机器人数量、敞口和未结订单。
- `所有交易`：查看所有订单记录。
- `所有持仓`：查看当前持仓。

巡检顺序：

1. 留在 `概览`，核对机器人列表和状态徽章。
2. 点击 `所有交易`，查看订单列表能否加载。
3. 点击 `所有持仓`，查看持仓列表能否加载。
4. 事件流区域可筛选：`全部`、`决策`、`订单`、`事件`；也可切换音量前缀显示。只切换筛选，不停止机器人。

### 5.2 机器人行操作

机器人行内通常包含启动/停止、激活/停用、风险限额等操作。第一遍巡检只查看按钮状态，不点击 `停止` 或停用。若看到红色阻断状态，记录机器人名称和时间，再去日志中核对。

## 8. 账户页面

### 8.1 进入账户页

1. 点击左侧导航 `账户`。
2. 页面顶部有 `账户设置`。
3. 主标签：`概览`、`沙盒交易台`、`实盘交易台`。

### 8.2 沙盒交易台

1. 点击 `沙盒交易台`。
2. 内部标签：`概览`、`持仓`、`交易日志`。
3. 可见按钮：
   - `新建`：创建新沙盒账户。
   - `刷新交易台`：手动刷新账户列表。
   - 账户行内 `打开`：进入该账户详情。
   - `聚焦交易台`：聚焦当前交易台视图。

#### 新建沙盒账户弹窗（只查看，可不创建）

1. 点击 `新建`，弹出标题为 `新建沙盒账户` 的弹窗。
2. 字段：
   - `账户名称`：最长 100 字符。
   - `初始资金（USD）`：允许范围 100–10,000,000。
   - `单仓上限（%）`：允许范围 1–100。
   - `最大持仓数`：允许范围 1–100 的整数。
3. 底部按钮：`取消`、`创建`。
4. 若只是巡检，点击 `取消`；若确实要练习沙盒开户，填写示例名称和合理资金后点击 `创建`。

#### 查看已有沙盒账户

1. 在账户行点击 `打开`。
2. 分别查看内部标签 `概览`、`持仓`、`交易日志`。
3. 返回列表后点击 `刷新交易台`，确认账户数据能刷新。

### 8.3 实盘交易台

1. 点击 `实盘交易台`。
2. 当前未配置 Polymarket 实盘凭证时，页面应显示未连接或空状态。
3. 不要在未配置凭证的情况下点击实盘下单或连接按钮。

### 8.4 风险雷达

账户页下方显示风险雷达，本机核对时可见：

- 沙盒账户在线数量。
- 已连接实盘平台数量；当前为 0/2 属单平台上线前的正常状态。

1. 点击左侧导航 `策略`。

   - `刷新目录`：刷新策略目录。

### 9.2 研究与回测工作室

1. 点击 `研究` 子标签。
2. 顶部策略下拉框：当前显示已加载策略，例如 `Basic Arbitrage`；点击下拉箭头可选择其他策略。
3. 研究模式按钮：
   - `代码实验`

   - `3 Inspect REVIEW RESULTS`

6. 窗口预设：
   - `快速 — 1 天窗口`
   - `标准 — 7 天窗口`

8. 底部按钮：`Continue to Run`。

## 14. 紧急停止与恢复（只在异常时使用）

### 14.1 暂停全局调度

- 顶部 `Pause` 按钮：暂停 worker 调度。
- 暂停后按钮文案变为 `Resume`；确认要恢复时再点击。

### 14.2 机器人停止

- `机器人` 页面顶部 `停止`：停止机器人调度。
- 机器人行内的 `停止`：停止单个机器人。
- 红色 `Kill Switch` / 急停阻断：阻断实盘或自动执行，只在发现异常下单、资金风险或页面状态不可控时使用。

### 14.3 巡检时不要做的事

- 不要删除数据库、缓存目录或已录制数据集。
- 不要点击实盘订单的 `确认实盘订单`。
- 不要修改 VPN/代理、RPC、数据库自动清理配置。
- 不要把 `news` worker 的琥珀色警告误判为系统崩溃；它是当前主动停用的新闻源。
- 不要期待 Kalshi 市场入口恢复；跨平台策略已停用，恢复需要重新验收网络出口和真实行情。
